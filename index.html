SEU MÉTODO · REPOSITÓRIO PRIVADO
Abra seu quadro de qualquer lugar.
O quadro fica salvo em engcolombo/SMC_Agentes. Conecte uma credencial do GitHub para ler e salvar suas anotações.
  1. Abra Criar credencial no GitHub ↗ e dê um nome como “Editor SMC”.
  2. Em Repository access → Only select repositories, selecione somente SMC_Agentes.
  3. Em Repository permissions, escolha Contents → Read and write. Defina a validade e clique em Generate token.
  4. Copie a credencial e cole abaixo. Em outro aparelho, use a mesma credencial válida ou crie outra.
A credencial vai diretamente à API do GitHub e fica somente na memória desta aba. Ao recarregar, conecte novamente. Suas anotações permanecem no GitHub.
